Allen-Bradley CompactLogix Studio 5000 (LD) Remote Commissioning

Automated Silo Batching System

Design, programming, and remote commissioning of an automated material dosing sequence. This project validates logic using a physical CompactLogix 5370 controller located in Houston, TX, accessed securely via a Tailscale mesh VPN from Edmonton, AB. Physical process simulation was achieved using LogixPro.

I/O Mapping & Variables

Tag Name Type Function
Prox_Sensor_Silo DI (BOOL) Detects exact container positioning under the discharge valve.
Level_Sensor_High DI (BOOL) Indicates container has reached maximum volumetric capacity.
Valve_Solenoid DO (BOOL) Actuates the opening/closing of the silo discharge gate.
Motor_Conveyor DO (BOOL) Controls the advancement of the container transport belt.

Fail-Safe Engineering

  • Interlocking: Strict conditional logic prevents the conveyor motor from starting while the discharge valve is open, avoiding material spills.
  • Guarding: Immediate discharge halt upon loss of the proximity sensor signal.
  • Scalability: Industry-standard tag naming conventions to facilitate future SCADA integration (Ignition) or multi-silo expansion.
